# 🌍 Traveloop

Traveloop is a personalized travel planning platform that helps users create multi-city itineraries, manage budgets, explore destinations, and organize trips easily.

---

## ✨ Features

- 🔐 User Authentication (Login/Signup)
- 🗺️ Multi-city itinerary planning
- 📅 Day-wise travel scheduling
- 💰 Budget estimation & cost tracking
- 🏙️ City and activity search
- 🎒 Packing checklist
- 📝 Trip notes/journal
- 📤 Share public itineraries
- 📊 Analytics dashboard (optional)

## 🚀 Installation

### Clone Repository

```bash
[git clone https://github.com/your-username/Traveloop.git](https://github.com/shraddhajain0989/Traveloop.git)
```

### Navigate to Project

```bash
cd Traveloop
```

### Install Dependencies

```bash
npm install
```

### Run Project

```bash
npm start
```
